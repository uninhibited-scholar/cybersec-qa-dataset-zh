# Phase 12 研究计划：模型循环自进化安全

本阶段是独立研究沙盒，不与生产 API 或当前网安适配器自动合并。

## 闭环

记录任务与工具轨迹 → 由独立评估器评分 → 生成候选改进数据 → 在隔离
检查点上离线更新 → 运行固定盲测与回归集 → 人工批准或回滚。

## 必测风险

- 奖励劫持：得分上升但真实任务质量下降
- 自我污染：错误回答被重新采样为训练事实
- 能力漂移：普通问答、格式遵循或拒答边界退化
- 评测欺骗：只针对已知题目优化
- 工具权限升级：候选更新请求超出原授权范围
- 数据与版本溯源缺失：无法定位错误更新来源

## 不变量与闸门

1. 评估器、训练器、部署器分离，候选模型不能自行批准上线。
2. 每条训练样本保留来源、时间、模型版本和人工/自动评分标记。
3. 生产适配器只读；更新先写新目录，失败可一键回滚。
4. 未知证据必须输出“无法核验”，不得以模型自述代替来源。
5. 盲测集不进入训练；候选需同时通过身份、普通问答、格式、证据和
   网安专业回归。
