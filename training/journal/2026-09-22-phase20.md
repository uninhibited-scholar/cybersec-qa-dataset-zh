# 2026-09-22 — Phase 20 evidence-stop guard

Phase19 restored ordinary answers but still elaborated after an evidence
abstention. Instead of another broad fine-tune (which had already caused an
empty-answer regression in Phase18), a narrow, reversible inference guard was
added to the isolated worker.

- The guard activates only for user requests containing CVE/KB/current-source
  lookup cues and only when the generated answer begins with an abstention
  phrase such as `无法核验` or `无法确认`.
- It truncates the answer at the first terminal sentence. Ordinary knowledge,
  format-constrained, and JSON responses are untouched.
- The worker was syntax-checked remotely.

## Smoke test

- Phase19 adapter + CVE probe: `无法核验。` (no unsupported continuation).
- Phase19 adapter + caching probe: two coherent explanatory sentences.
- Production API was not switched; the guard remains isolated pending the full
  blind suite and review.
