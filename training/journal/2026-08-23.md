# 2026-08-23 — Private remote API transport

## Objective

Make the Mac mini model API reachable from the MacBook outside the home LAN without exposing the raw inference port to the public Internet. Preserve the Harness endpoint `http://127.0.0.1:18764/v1`.

## Result

- Mac mini API remained bound to `127.0.0.1:18766` and reported `{"status":"ok","model":"qwen-cyber-local"}`.
- Added the MacBook and Mac mini to the same Tailscale account using userspace networking.
- Tailscale addresses at setup time:
  - MacBook: `100.66.223.112`
  - Mac mini: `100.93.176.125`
- Verified SSH to the Mac mini through `tailscale nc`, using the existing LAN host key via `HostKeyAlias=192.168.2.68`.
- Installed a persistent MacBook SSH forward:
  - `127.0.0.1:18764` -> Tailscale SSH -> Mac mini `127.0.0.1:18766`
- Installed per-user LaunchAgents for both Tailscale daemons and the MacBook API tunnel.
- Final health request through the persistent tunnel succeeded.

## Security properties

- No raw model API port is exposed to the public Internet.
- The API remains protected by its existing bearer token.
- No Tailscale credentials, API tokens, private keys, model weights, or private datasets are committed.
- Access requires membership in the same Tailscale network plus the existing SSH identity.

## Reproducible configuration

- `training/network/com.uninhibited-scholar.tailscaled-cyber-macbook.plist`
- `training/network/com.uninhibited-scholar.tailscaled-cyber-mini.plist`
- `training/network/com.uninhibited-scholar.cyber-api-tunnel.plist`

Installed copies live in each user's `~/Library/LaunchAgents/` directory. Runtime state and logs live under `~/.config/tailscale-cyber/` and are intentionally outside Git.

## Recovery checks

```bash
launchctl print gui/$(id -u)/com.uninhibited-scholar.tailscaled-cyber
launchctl print gui/$(id -u)/com.uninhibited-scholar.cyber-api-tunnel
curl --max-time 12 http://127.0.0.1:18764/health
```

## Failure observed

The first tunnel health check failed because the SSH LaunchAgent started before the Tailscale daemon was ready. `KeepAlive` and `ThrottleInterval=10` retried automatically; the tunnel then entered the running state and the API health check passed. Restarting the Mac mini Tailscale daemon also briefly reset the tunnel, which recovered automatically as intended.
