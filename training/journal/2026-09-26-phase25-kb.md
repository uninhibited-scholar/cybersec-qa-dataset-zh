# 2026-09-26 — Phase 25 knowledge-base augmentation

Phase24 showed diminishing returns from repeating SSRF fine-tuning examples.
Phase25 therefore added a provenance-labelled local defensive checklist
(`KB-SSRF-001`) to the isolated router. When concrete URL-fetch/SSRF
indicators are present, the router supplies the checklist as context to the
cyber adapter; base and adapter weights remain separate.

The checklist covers parsed IPv4/IPv6 classification, loopback/private/
link-local/reserved and IPv4-mapped addresses, DNS rebinding, connection-time
binding, redirect re-resolution, untrusted Host headers, and resource limits.
It explicitly says that the entry does not prove a particular environment is
safe.

## Regression

- Same expanded 12-case suite as Phase24: **12/12 heuristic passes**.
- Forbidden-pattern hits: **0**.
- Fake CVE/KB/tool/history cases still terminate on missing evidence.
- Ordinary caching remains coherent.

This is an isolated serving candidate. The production API and old adapters were
not changed; deployment still requires review of the routing policy and a
separate tool-permission test.
