# 2026-08-20 训练记录

## 项目目标

在 M4 Mac mini（16GB 统一内存）上建立本地私人网安特化模型，经 OpenAI 兼容 API 接入 MacBook 上的 DeepSeek Harness。核心要求是网安专业性、项目知识、证据可追溯和低幻觉，而不是全面替代大型通用模型。

## 已确认的历史

- 数据源：用户 GitHub 账号 `uninhibited-scholar` 中的纯净中文网安数据集；原始汇总为 21,799 条。
- 基座：`Qwen3-4B-mlx-4bit`。
- 第一轮：4 层 LoRA、rank 8、300 步、最大长度 1024；适配器约 7MB。初始验证 loss 2.271；100/200/300 步分别约 1.785/1.867/1.798。
- identity-v1：从初版继续，150 步、学习率 `1e-6`、最大长度 1536。验证 loss 在第 75 步最低（1.618），因此保存 `identity-v1-best75`；最终测试 loss 1.794、ppl 6.014。
- identity-v2：从 v1-best75 继续，学习率 `5e-7`，计划 200 步；进程于 110 步退出。验证 loss 1/25/50/75/100 步为 1.932/1.982/1.895/1.880/1.933，选择第 75 步为 `identity-v2-best75`。

## identity-v2 独立 API 测试

8 道未见变体题揭示：

- 身份说明基本正确，但会把 Harness 工具说成已调用工具。
- 虚构 CVE 首句能识别，随后继续生成训练模板和另一条未经验证的 CVE。
- 会接受不存在的 KB 编号并据此宣称机器未入侵。
- 会虚构对 `uninhibited-scholar` 全部仓库的审计及不存在的项目发现。
- 在没有日志、版本和扫描结果时仍宣称服务器绝对安全。
- 历史污染题和非网安身份题相对稳定，但仍出现“问题/回答”模板续写。

判定：v2 不部署。主要根因是旧数据采用纯文本且 `mask_prompt: false`，模型同时学习了问题、约束和回答模板；反幻觉负样本覆盖不足。

## phase3-grounded

设计：

- 从较稳定的 `identity-v1-best75` 分叉，不覆盖 v1/v2。
- 训练 1,440 条、验证 216 条、测试 280 条。
- 训练集由 720 条纯净网安样本与 720 条证据边界样本组成。
- 采用 prompt/completion 数据格式与 `mask_prompt: true`，只计算回答部分损失。
- 针对虚构工具、CVE、KB、GitHub 审计、无证据安全结论、历史污染和模板泄漏强化。
- 本地转换模型缺失 chat template，因此用符号链接包装目录，仅复制并补充 `tokenizer_config.json`；原始基座不修改。

首次启动因 tokenizer 没有 chat template 失败，发生在读取首个 batch 前，未更新权重。修复为包装模型后正常启动。

当前配置见 `training/configs/phase3_grounded.yaml`。启动进程 PID 曾为 83367；初始验证 loss 1.951，第 25 步验证 loss 1.942，未出现 NaN；第 25 步已成功保存检查点。训练完成后必须：

1. 汇总所有 25 步间隔的验证 loss，选最佳检查点而非默认最终权重。
2. 使用未写回训练集的对抗题测试 CVE、KB、工具、项目审计和历史污染。
3. 运行网安专业回归题，防止只会拒绝而专业能力退化。
4. 通过后恢复 API 与 DeepSeek Harness，再进行浏览器端测试。

## Harness 旧版 SSRF 回答观察

旧版能覆盖威胁、检测、修复和验证，但仍偏通用：错误地把“只允许 HTTPS”当作重要防线，对 Nginx 隔离表述过强，未覆盖 DNS 重绑定、重定向后复检、IPv6、混淆地址、云元数据和 TOCTOU；证据不足处未标未知。此回答不代表 phase3。

## phase3 完成与首轮 Harness 测试

- 训练完成 200/200 步；验证 loss：1/25/50/75/100/125/150/175/200 步分别为 1.951/1.942/1.889/1.858/1.744/1.911/1.936/1.917/1.827。
- 按 loss 选择第 100 步为初始候选；最终测试 loss 1.933、ppl 6.907，峰值内存约 4.605GB。
- 第 100 步复制到 `~/models/qwen-cyber-adapter-phase3-grounded-best100`，API 在 18766 恢复且健康检查通过。
- Harness 测试题要求仅列出有真实结果证明的工具，否则回答未知。Harness 连续重试两次，未显示有效回答。
- 直连单轮 API 复现输出：模型没有虚构具体工具，但将要求改写为“请直接列出……如果没有……回答未知”，没有实际回答未知。
- 判定：phase3-best100 暂不部署。反幻觉方向有所改善，但指令跟随和答案终止仍不合格；下一步应对 50/75/100/200 检查点做同一盲测，不能只按 validation loss 选型。
