# KB-SSRF-001 — URL 抓取接口检查清单

用途：授权代码审查与防御验证。该条目只提供防御性检查要点，不代表对任何具体环境已经完成验证。

必须检查：

1. 解析 URL 后校验协议、端口和最终解析出的每个 IPv4/IPv6 地址；拒绝回环、私网、链路本地、多播、保留地址和 IPv4-mapped IPv6。
2. 不用字符串匹配替代 IP 解析；不能只拦 `127.0.0.1`，还要覆盖 `::1`、其他回环地址和非标准数字表示。
3. 发起连接前绑定已校验的目标 IP，并在连接后确认实际对端没有变化，防止 DNS rebinding。
4. 每次 HTTP 重定向都重新解析、重新做地址分类和策略检查；限制重定向次数、响应大小、超时和协议升级。
5. 不信任用户可控的 Host、X-Forwarded-Host、X-Real-IP 等头部来决定目标地址；以解析结果和实际连接为准。

证据边界：没有代码、配置、日志或测试回执时，只能说明检查方法，不能断言某个环境已经安全或已经存在漏洞。
