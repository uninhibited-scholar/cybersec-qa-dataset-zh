# Phase29 production API guard patch plan

## 当前差异

生产 API `18765` 的 API 层工具声明规则尚未覆盖“执行扫描工具”“调用扫描工具”“给出真实返回码”。同一请求在生产端会进入模型生成，而不是返回确定性的无工具证据拒答。

## 已验证补丁

仅在 canary 副本 `18766` 的 `tool_claim_words` 中加入上述三个短语。重启 canary 后，健康检查为 `ok`，同一请求返回 `no_tool_evidence_answer()`，没有触碰生产进程。

## 正式切换前检查

1. 备份 `api_server_identity.py` 并记录 SHA-256；
2. 只加入三个短语，不改变模型路径、适配器路径或端口；
3. 重启生产 API；
4. 运行健康检查、无害普通问答、无工具回执拒答和带 tool result 的正向回归；
5. 任一检查失败立即恢复备份；
6. 将生产前后哈希、日志和结果写入 Git。

此计划不授权生产切换；当前生产 API 保持原样。
